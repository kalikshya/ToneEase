ToneEase
AI-powered tone detection for better communication

What it does

ToneEase analyzes your messages in real time and suggests kinder, more professional rewrites using the Llama 3.3 70B model via the Groq API.

Supported platforms

WhatsApp Web, Facebook Messenger, Instagram Direct, and any text input via the extension popup.

Built with

FastAPI Groq API Llama 3.3 70B MySQL Chrome MV3
